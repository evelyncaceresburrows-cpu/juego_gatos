# Carpeta `outputs/`

Aquí Claude entrega los archivos listos para implementar, uno por mejora.

## Convención de nombres

`mejora-NN.<ext>` donde:
- `NN` es el número de la mejora según `mejoras/prompts-mejoras.md`.
- `<ext>` es la extensión apropiada al destino: `.tsx`, `.ts`, `.css`, `.html`.

## Convención de cada archivo

Comentario inicial obligatorio en español:

```
// Mejora NN — <título corto>
// Destino: <ruta del archivo del proyecto>
// Acción: <reemplaza | agrega bloque | añade al final | etc.>
```

Después del comentario, el código va listo para copy-paste sin TODOs ni placeholders.
